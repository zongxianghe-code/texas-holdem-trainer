# Texas Hold'em Trainer 德州扑克训练器

一个在浏览器里运行的**德州扑克（无限注）训练器**，有两种模式：

- **🤖 人机对战 6人桌（默认）**：你控制一个座位，另外 5 个座位由电脑操控。电脑翻牌前按位置范围表混合频率行动，翻牌后使用启发式策略。右侧 **GTO 风格建议面板**给出推荐频率、下注尺度和 **“为什么”理由**，并在你行动后提示“符合 / 偏离”及原因。每手结束后可**查看所有电脑的底牌**复盘；输光后可**按平均筹码重新买入**。
- **👥 自对弈（热座）**：一个人操控牌桌上的所有座位（2–9 人），轮流替每位玩家做决定。由于能看到所有人的底牌，训练面板会显示**对其他玩家真实手牌的胜率**。

> ⚠️ **关于“GTO”**：翻牌前范围表是依据常见公开的 6-max 100BB 图表整理并简化的**近似范围**，翻牌后建议是**启发式近似建议，非求解器（solver）结果**。它们适合建立直觉，但不等于精确的博弈论最优解。

纯前端实现（HTML + CSS + 原生 JavaScript ES 模块），无需后端、无需构建，GitHub Pages 直接托管。

## 怎么玩

### 人机对战 6人桌（默认模式）

1. 在设置界面选择“人机对战 6人桌”，设置**你的座位**（默认座位 1）、**电脑难度**（标准 / 简单）、**电脑速度**（慢 / 正常 / 快 / 瞬间）、初始筹码与盲注。
2. 你的座位显示为“你”，电脑为“电脑2”…“电脑6”。电脑会在短暂延迟后自动行动（顶栏可随时调整速度）。
3. 电脑底牌在手牌进行中隐藏；训练时可在设置或顶栏打开“显示电脑手牌”（打开后才会显示基于真实手牌的胜率，否则只显示对**估计范围**的胜率，不会泄露电脑底牌）。
   - **每手结束后查看电脑手牌**（设置与顶栏开关，默认开启）：每手牌结束后——包括所有人弃牌、没有摊牌的情况——把所有电脑的底牌在牌桌上翻开，并在结算区显示**本手复盘**：每个电脑的底牌、（公共牌发完时的）最终牌型与最佳五张、在哪条街弃牌、以及它每条街的动作；复盘内容同时写入牌局日志。手牌进行中电脑底牌始终保持隐藏（除非打开“显示电脑手牌”）。
4. 轮到你行动时，**GTO 建议**面板显示：
   - **翻牌前**：你的位置与点位（开池 / 面对开池 / 面对 3bet / 面对 4bet / 有人溜入…）、起手牌类别与强度排名、范围表中的推荐频率（如 *加注 70% / 跟注 0% / 弃牌 30%*）和推荐尺度（以大盲为单位，见下文），并可展开当前点位的 **13×13 范围图**。
   - **翻牌后**：牌型、听牌、牌面结构（干燥/湿润）、位置、SPR、对估计范围的胜率与所需胜率，以及动作频率和尺度分类（价值下注 / 半诈唬 / 诈唬 / 过牌控池 / 抓诈跟注 / 弃牌），明确标注“**近似建议，非求解器结果**”。
   - **为什么**：每条建议附 2–4 条简短理由，由规则模板根据当前局面生成（**不编造求解器数据**）。翻牌前涉及：位置与身后人数、范围宽度、起手牌特征（同花/连张/对子/高张）、阻断牌、被压制风险、混合频率的含义、尺度依据；翻牌后涉及：胜率与底池赔率要求、最小防守频率（MDF）、牌面结构、范围/坚果优势、价值/诈唬/过牌的逻辑、听牌与补牌数、尺度依据。
5. 你行动后会立刻得到反馈：**符合 / 基本符合（低频选项）/ 偏离**，并给出理由（偏松、偏紧、偏被动或偏激进的具体原因，尺度是否与建议一致）。
6. 你输光后可以**按平均筹码重新买入**（开启“允许重新买入”时），也可以继续观看电脑对局，或重新开始。

### 自对弈（热座）

1. 在设置界面选择“自对弈”，设置**玩家人数（2–9 人）**、**初始筹码**、**小盲 / 大盲**，以及是否显示所有玩家的手牌（默认开启）。
2. 座位依次命名为 玩家1、玩家2 …，白色 **D** 为庄家按钮，SB / BB 标出大小盲。轮到谁行动，谁的座位就会**金色高亮**，由你替他做决定（建议面板同样适用于当前行动座位）。

### 操作与下注尺度

- **弃牌 / 过牌 / 跟注 / 下注 / 加注 / 全下**
- **翻牌前：常规的大盲尺度**
  - 开池：UTG / HJ / CO / BTN 开到 **2.5BB**，小盲开到 **3BB**（单挑时庄家按 BTN 处理）
  - 隔离溜入者：**3BB + 每名溜入者 1BB**
  - 3bet：有位置约 **3 倍**，无位置（SB / BB）约 **4 倍**；挤压（前面有开池且有人跟注）：**4 倍 + 每名跟注者 1 倍**
  - 4bet：约 **2.2 倍**；5bet：**全下**
  - 快捷按钮按大盲计：无人加注时 *最小 / 2BB / 2.5BB / 3BB*（有溜入者时每人 +1BB），面对加注时 *最小 / 3x / 4x*，面对 3bet 及以上时 *最小 / 2.2x / 3x*；另有滑杆 / 输入框和“全下”按钮。
- **翻牌后：只有四种底池比例**：**1/3 池、1/2 池、2/3 池、4/3 池（超池）**，快捷按钮为 *最小 / 1/3 池 / 1/2 池 / 2/3 池 / 4/3 池*，另有滑杆 / 输入框和“全下”。
  - 计算方式：下注到 = 当前最高下注 + 比例 ×（底池 + 跟注所需）。
- 电脑的下注和建议面板推荐的尺度遵循同样的规则，所有尺度都会限制在合法的最小加注与全下之间。
- 快捷键：`F` 弃牌、`C` 过牌/跟注、`R` 下注/加注、`回车` 下一手

### 训练辅助面板

右侧**训练辅助**面板显示当前行动玩家的：

- 当前牌型（高牌 / 一对 / 两对 / 三条 / 顺子 / 同花 / 葫芦 / 四条 / 同花顺 / 皇家同花顺）及最佳五张
- 胜率：自对弈或打开“显示电脑手牌”时为对所有在局对手**实际手牌**的胜率（翻牌前蒙特卡洛 3000 次；翻牌、转牌精确枚举；河牌直接比较）；人机模式隐藏电脑底牌时为对**估计范围**的胜率
- 底池、需跟注金额、底池赔率（需要多少胜率跟注才不亏）以及简化的跟注 EV
- 显示所有手牌时还会列出每位在局玩家的手牌、牌型和胜率条

一手结束后查看结算（主池 / 边池、赢家、牌型），点击“下一手”继续。

### 重新买入（设置项“允许重新买入”，默认开启）

- 电脑输光（一手结束时筹码为 0）后，在下一手开始前**自动重新买入**，牌桌保持 6 人。
- 买入金额 = **仍有筹码的玩家的平均筹码**，取整到大盲的整数倍；至少 1 个大盲，且不低于 min(20BB, 初始筹码)。
- 你输光时，结算区提供 **“按平均筹码重新买入”** 按钮，同时保留“继续观看电脑对局”和“再来一局”。
- 每个座位显示**净盈亏**（筹码 − 累计买入）和买入次数；侧栏 **“筹码统计”** 列出每个座位的重新买入次数、累计买入与净盈亏，并核对“桌面总筹码 = 累计买入”。每次重新买入都会写入牌局日志。
- 自对弈模式同样适用：输光的玩家自动按平均筹码买入。关闭该选项时，输光的玩家出局，最后剩一人时游戏结束。自对弈模式关闭“显示所有手牌”后，只显示**正在行动的玩家**的底牌（摊牌时亮牌），更接近真实信息条件。

## 功能列表（v0.3）

- **人机对战 6人桌**：选择座位，5 个电脑对手（标准 / 简单难度），可调速度（含瞬间），电脑底牌摊牌前隐藏（可打开显示）
- **电脑 AI**：
  - 翻牌前按位置（UTG/HJ/CO/BTN/SB/BB）查范围表：开池、面对开池的 3bet/跟注、面对 3bet 的 4bet/跟注/弃牌、大盲防守、面对溜入的隔离加注等，按混合频率随机执行
  - 翻牌后根据对“估计范围”的胜率（按对手翻牌前动作从范围表推断并加权的蒙特卡洛）、牌面结构、听牌、底池赔率、SPR、位置、是否翻牌前进攻者，决定持续下注频率与尺度、价值下注、半诈唬、偶尔过牌加注与诈唬，随机性有界
  - 只使用公开信息和自己的底牌（有单元测试验证），所有动作都经过引擎的合法动作 API 校正
- **GTO 风格建议**：翻牌前范围表频率 + 13×13 范围图，翻牌后近似建议，每条建议附 2–4 条规则生成的“为什么”，行动后反馈“符合 / 偏离”及理由
- **下注尺度**：翻牌前用常规大盲尺度（2.5BB 开池、3BB 小盲开池、3/4 倍 3bet、挤压、2.2 倍 4bet、5bet 全下），翻牌后只用 1/3、1/2、2/3、4/3 底池；界面、电脑和建议统一使用
- **每手结束后查看电脑手牌**：包括弃牌结束的手牌，附复盘摘要（底牌、最终牌型 / 最佳五张、各街动作）并写入日志
- **重新买入**：电脑输光自动按平均筹码买入保持满桌，人类可一键买入；显示每个座位的买入次数、累计买入与净盈亏
- 2–9 人自对弈牌桌，自定义初始筹码和盲注，一人操控所有座位
- 完整无限注规则：
  - 庄家按钮轮转（自动跳过出局玩家），大小盲，短筹码盲注全下
  - 翻牌前 / 翻牌 / 转牌 / 河牌四轮下注，正确的行动顺序（含**单挑规则**：庄家下小盲、翻牌前先行动、翻牌后后行动）
  - 大盲的“选择权”（limp 后可加注）
  - **最小加注规则**：加注幅度至少等于上一次完整加注；不足额的全下加注**不会重新开放**已行动玩家的加注权
  - 未被跟注的下注自动退还
- 7 选 5 最佳牌型评估，摊牌比牌，**平分底池**（零头筹码按庄家左侧顺序分配），多层**边池**
- 无人可继续下注时（全下）自动发完公共牌
- 玩家出局与游戏结束判定
- 胜率 / 底池赔率 / 牌型等训练辅助
- 牌局日志：每条街的动作、公共牌、亮牌、赢家与金额、复盘底牌、重新买入
- 椭圆形绿色牌桌、♠♥♦♣ 红黑花色牌面，桌面与手机宽度自适应

## 本地运行

ES 模块需要通过 HTTP 访问（直接双击打开 `index.html` 会被浏览器拦截）：

```bash
git clone https://github.com/zongxianghe-code/texas-holdem-trainer.git
cd texas-holdem-trainer
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

## 已知限制

- **“GTO”建议不是求解器结果**：翻牌前范围是公开图表的近似整理（小盲采用加注或弃牌、多人底池沿用单挑范围、超过 6 人时多出的前位按 UTG 处理、单挑时庄家按 BTN 范围处理）；翻牌后是启发式规则，没有考虑完整的范围对抗与平衡。
- 翻牌前尺度是固定的常规值（不随筹码深度、对手或桌况调整），翻牌后只有四种底池比例；短筹码时往往被限制为全下。
- “为什么”理由由规则模板生成，解释的是本训练器自己的近似策略，不是求解器给出的原因；个别局面下理由可能偏简化。
- 重新买入按“平均筹码”计算，多名玩家同时输光时桌面总筹码会明显增加；净盈亏只统计本局（刷新页面后不保留）。
- 电脑的范围推断只基于翻牌前动作，翻牌后只做简单收窄；电脑没有针对对手的剥削性调整，“简单”难度只是更松更被动。
- 翻牌后建议的胜率为蒙特卡洛估计（建议 1500 次、电脑 400 次），有随机误差。
- 底池赔率与“跟注 EV”是简化计算：只考虑当前底池中该玩家能赢得的部分，不考虑后续街的下注和多人边池的复杂情况。
- 胜率是基于所有在局玩家**真实手牌**的“上帝视角”胜率，不是对范围（range）的胜率。
- 翻牌前胜率为 3000 次蒙特卡洛模拟，存在约 ±1% 的随机误差；计算在主线程进行。
- 暂不支持：前注（ante）、盲注升级、固定限注/底池限注、撤销动作、保存/读取牌局。
- 出局座位采用简单的“移动庄家按钮”规则，没有实现“死按钮”规则。
