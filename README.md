# Texas Hold'em Trainer 德州扑克训练器

一个在浏览器里运行的**德州扑克（无限注）自对弈训练器**：一个人操控牌桌上的所有座位，轮流替每位玩家做决定，自己和自己对局。由于你能看到所有人的底牌，训练面板会显示**对其他玩家真实手牌的胜率**、跟注所需的底池赔率和当前牌型，帮助你建立对胜率、赔率和下注尺度的直觉。

纯前端实现（HTML + CSS + 原生 JavaScript ES 模块），无需后端、无需构建，GitHub Pages 直接托管。

👉 **https://zongxianghe-code.github.io/texas-holdem-trainer/**

## 怎么玩

1. 在设置界面选择**玩家人数（2–9 人）**、**初始筹码**、**小盲 / 大盲**，以及是否开启“训练模式：显示所有玩家的手牌”（默认开启）。
2. 点击“开始游戏”。座位依次命名为 玩家1、玩家2 …，白色 **D** 为庄家按钮，SB / BB 标出大小盲。
3. 轮到谁行动，谁的座位就会**金色高亮**。在下方行动面板替他选择：
   - **弃牌 / 过牌 / 跟注 / 下注 / 加注 / 全下**
   - 用**滑杆**或输入框设置金额，或用快捷按钮：**最小、1/2 池、2/3 池、底池**
   - 快捷键：`F` 弃牌、`C` 过牌/跟注、`R` 下注/加注、`回车` 下一手
4. 右侧**训练辅助**面板显示当前行动玩家的：
   - 当前牌型（高牌 / 一对 / 两对 / 三条 / 顺子 / 同花 / 葫芦 / 四条 / 同花顺 / 皇家同花顺）及最佳五张
   - 对所有在局对手**实际手牌**的胜率（翻牌前蒙特卡洛 3000 次；翻牌、转牌精确枚举；河牌直接比较）
   - 底池、需跟注金额、底池赔率（需要多少胜率跟注才不亏）以及简化的跟注 EV
   - 训练模式下还会列出每位在局玩家的手牌、牌型和胜率条
5. 一手结束后查看结算（主池 / 边池、赢家、牌型），点击“下一手”继续。筹码输光的玩家出局，最后剩一人时游戏结束。
6. 关闭顶栏的“显示所有手牌”后，只显示**正在行动的玩家**的底牌（摊牌时亮牌），更接近真实信息条件。

## 功能列表（v0.1）

- 2–9 人牌桌，自定义初始筹码和盲注，一人操控所有座位
- 完整无限注规则：
  - 庄家按钮轮转（自动跳过出局玩家），大小盲，短筹码盲注全下
  - 翻牌前 / 翻牌 / 转牌 / 河牌四轮下注，正确的行动顺序（含**单挑规则**：庄家下小盲、翻牌前先行动、翻牌后后行动）
  - 大盲的“选择权”（limp 后可加注）
  - **最小加注规则**：加注幅度至少等于上一次完整加注；不足额的全下加注**不会重新开放**已行动玩家的加注权
  - 未被跟注的下注自动退还
- 7 选 5 最佳牌型评估，摊牌比牌，**平分底池**（零头筹码按庄家左侧顺序分配），多层**边池**
- 无人可继续下注时（全下）自动发完公共牌
- 玩家出局与游戏结束判定
- 胜率 / 底池赔率 / 牌型等训练辅助
- 牌局日志：每条街的动作、公共牌、亮牌、赢家与金额
- 椭圆形绿色牌桌、♠♥♦♣ 红黑花色牌面，桌面与手机宽度自适应

## 本地运行

ES 模块需要通过 HTTP 访问（直接双击打开 `index.html` 会被浏览器拦截）：

```bash
git clone https://github.com/zongxianghe-code/texas-holdem-trainer.git
cd texas-holdem-trainer
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

## 运行测试

单元测试使用 Node.js 内置测试运行器，**无需安装任何依赖**（需要 Node.js 18+，已在 Node 20 上验证）：

```bash
node --test        # 或 npm test
```

测试覆盖：

- `tests/evaluator.test.js`：各牌型识别与大小比较、踢脚、A-5 顺子；穷举全部 2,598,960 种五张牌验证各牌型数量；随机七张牌与独立的朴素评估器交叉验证
- `tests/engine.test.js`：单挑与多人行动顺序、大盲选择权、最小加注、不足额全下不重新开放加注、边池、平分底池与零头筹码、短筹码大盲、出局与庄家轮转、非法动作，以及随机对局压力测试（筹码守恒）
- `tests/equity.test.js`：AA 对 KK 胜率、河牌平分、转牌/翻牌精确枚举
- `tests/static.test.js`：页面引用的资源存在、模块可在无 DOM 环境导入

可选的浏览器冒烟测试（需要 Chrome/Chromium 和 `playwright-core`）：

```bash
npm i --no-save playwright-core
python3 -m http.server 8000 &
CHROME=/usr/bin/google-chrome node scripts/smoke-browser.mjs http://127.0.0.1:8000/
```

## 代码结构

```

tests/              node --test 单元测试
scripts/            可选的浏览器冒烟测试
```

## 已知限制

- 底池赔率与“跟注 EV”是简化计算：只考虑当前底池中该玩家能赢得的部分，不考虑后续街的下注和多人边池的复杂情况。
- 胜率是基于所有在局玩家**真实手牌**的“上帝视角”胜率，不是对范围（range）的胜率。
- 翻牌前胜率为 3000 次蒙特卡洛模拟，存在约 ±1% 的随机误差；计算在主线程进行。
- 暂不支持：前注（ante）、盲注升级、固定限注/底池限注、撤销动作、保存/读取牌局。
- 出局座位采用简单的“移动庄家按钮”规则，没有实现“死按钮”规则。
